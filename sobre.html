♣ SOBRE O PROJETO

Mais amor, menos abandono.

O AdoteAmigo é um projeto acadêmico criado para apresentar uma experiência digital de adoção responsável de animais.

✣ NOSSA PROPOSTA

Uma interface pensada para aproximar pessoas e pets.

O projeto foi desenvolvido como uma aplicação web sobre adoção de animais, unindo design, organização de informações e uma experiência simples de navegação.

A ideia é mostrar como uma plataforma pode apresentar os pets de forma clara, explicar o processo de adoção e facilitar o primeiro contato entre interessado e equipe.

✣

Nosso trabalho

Este site faz parte de um projeto de desenvolvimento de interface, aplicando conceitos de cores, tipografia, composição visual, hierarquia, formatos de imagem e experiência do usuário.
